# 넘버런: 카운트랜드 대모험 🟥🟧🟨🟩🟦

> **NumberRun: Countland Adventure** — 숫자 블록 캐릭터로 즐기는 2D 횡스크롤 액션 플랫포머

숫자가 곧 몸이고, 몸이 곧 스킬입니다.
플러스 오브를 모아 **1부터 10까지** 자라면 캐릭터의 **모양·크기·이동 성능·필살기**가 통째로 바뀝니다.
크다고 항상 좋은 게 아니어서, 좁은 길은 작아져야 지나가고 두꺼운 벽돌은 6이 되어 굴러야 뚫립니다.

## 기술 메모

- **TypeScript + Vite**, 의존성 런타임 0개
- **에셋 파일 0개** — 모든 스프라이트·배경·효과음·BGM을 코드로 생성 (Canvas 2D + WebAudio)
- 논리 해상도 640×360, **고정 스텝(1/60s) 시뮬레이션** → 프레임레이트와 무관하게 물리 동일
- 축 분리 AABB 충돌, 코요테 타임 / 점프 버퍼 / 가변 점프 높이
- 세이브: `localStorage` (최고 점수, 설정)

```

src/engine/           AABB, 타일맵, 물리 (순수 함수 · 테스트 대상)

src/ui/               타이틀 · 스토리 · 일시정지 · 결과 화면
tools/gen_levels.py   레벨 그리드 생성기 (레벨 편집은 여기서)

```

### 개발 명령

```bash
npm run dev        # 개발 서버
npm run typecheck  # 타입 검사
npm test           # 단위 + 통합 테스트 (108개)
npm run check      # 타입 검사 + 테스트
npm run levels     # tools/gen_levels.py 로 레벨 데이터 재생성
npm run build      # 프로덕션 빌드 (dist/)
npm run build:single  # 단일 HTML 빌드 (dist-single/, 오프라인 배포용)
npm run shots      # 헤드리스 크롬으로 스크린샷 (preview 서버 실행 중일 때)
```

### 레벨 편집 방법

레벨은 문자 격자입니다. `tools/gen_levels.py` 를 수정하고 `npm run levels` 를 실행하면
`src/game/levels/data.ts` 가 다시 생성됩니다(직접 수정하지 마세요).
생성 시 다음을 자동 검사합니다: 시작점 1개, 골/보스 존재, 아이템이 벽에 박히지 않을 것.
`tests/levels.test.ts` 는 여기에 더해 **낭떠러지 폭·발판 유무·가장 큰 몸이 들어갈 공간**까지 검증합니다.

```
' ' 빈칸   '#' 지형   'B' 벽돌   '?' 아이템블록(코인)   '!' 아이템블록(오브)
'=' 한방향발판   '^' 가시   'L' 용암   'S' 단단한 돌
'P' 시작   'F' 골   'C' 체크포인트   'o' 코인   '+' 오브   'H' 하트
'm' 마이너스벌레   'b' 나눗셈박쥐   'z' 제로슬라임   'Z' 보스
'D' 좌우 이동발판   'V' 상하 이동발판   '1'~'9','0'(=10) 숫자 패드
```

## 접근성 / 어린이 모드

타이틀 메뉴에서 켤 수 있습니다. 라이프 5개, 피격 무적 시간 증가, 용암이 즉사 대신 −1이 됩니다.
숫자는 색뿐 아니라 **블록에 표기된 숫자와 모양**으로도 구분되도록 디자인했습니다.

## 캐릭터에 대하여

"눈이 달린 숫자 블록"이라는 보편적 콘셉트에서 출발한 **오리지널 디자인**입니다.
이름·색·능력·스토리는 모두 이 프로젝트 고유 설정이며, 외부 이미지·음원을 일절 사용하지 않고
전부 코드로 그려집니다.
