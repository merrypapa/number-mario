# 아트 & 사운드 스타일 가이드

## 원칙

1. **에셋 파일 0개.** 모든 스프라이트/배경/효과음은 런타임에 코드로 생성한다.
   (로딩 없음, 저작권 이슈 없음, 어떤 해상도에서도 선명)
2. **레트로 픽셀 룩.** 논리 해상도 640×360으로 렌더 후 정수배 확대,
   `imageSmoothingEnabled = false`.
3. **고대비 + 두꺼운 외곽선.** 어린이가 작은 화면에서도 형태를 구분할 수 있게.

## 팔레트

| 용도 | 색 |
|---|---|
| 하늘(위→아래) | `#4aa9f5` → `#a8dcff` |
| 먼 산 | `#7fc98d` / `#63b276` |
| 잔디 표면 | `#5fcf5a`, 흙 `#b3722f` / `#8b5420` |
| 벽돌 | `#c9773c` + `#8b4d22` 줄눈 |
| 아이템 블록 | `#f2c13d` + `#a9791a` |
| 코인 | `#ffd84d` / `#e0a51a` |
| 용암 | `#ff6b2b` → `#ffd04d` |
| 그림자/외곽선 | `#20232e` (순수 검정 대신 남색 계열) |

숫자 색은 `docs/CHARACTERS.md` 표를 단일 출처로 사용한다(`src/render/palette.ts`).

## 스프라이트 규격

- 타일 24×24px
- 플레이어 큐브 1칸 = 24×24px, 외곽선 2px, 상단/좌측 하이라이트 + 하단/우측 음영
- 눈: 흰자 반지름 4px, 동공 2px(진행 방향으로 이동)
- 팔다리: 3px 두께 라운드 라인, 걷기 사이클 4프레임

## 배경 레이어 (파랄랙스)

| 레이어 | 스크롤 계수 |
|---|---|
| 하늘 그라디언트 | 0.0 |
| 구름 | 0.15 |
| 먼 산 | 0.30 |
| 언덕/나무 | 0.55 |
| 타일맵 | 1.0 |
| 전경 풀숲 | 1.15 |

## 이펙트

- 착지 먼지, 대시 잔상, 블록 파편(4조각 물리), 코인 반짝임
- 획득 점수 플로팅 텍스트, 피격 시 캐릭터 흰색 플래시 + 화면 흔들림 6프레임
- 숫자 변화 시 블록이 위로 "쌓이는" 스케일 애니메이션 12프레임

## 사운드 (WebAudio 합성)

| 이벤트 | 음색 |
|---|---|
| 점프 | square, 440→880Hz 0.12s |
| 코인 | square 2음(B5→E6) |
| 숫자 업 | 상승 아르페지오 4음 |
| 피격 | sawtooth 하강 + 노이즈 |
| 스킬 | 숫자별 음정(도~미)의 짧은 chirp |
| 스테이지 클리어 | 6음 팡파레 |
| BGM | 8분음표 베이스 + 리드 2트랙 루프, 스테이지별 조성 변경 |
