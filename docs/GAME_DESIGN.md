# 넘버런: 카운트랜드 대모험 — 게임 기획서

> **NumberRun: Countland Adventure** · 2D 사이드 스크롤 액션 플랫포머

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 2D 횡스크롤 액션 플랫포머 (슈퍼마리오류) |
| 플랫폼 | 웹 브라우저 (HTML5 Canvas, 데스크톱 + 모바일 터치) |
| 타깃 | 5~10세 어린이 및 가족 (숫자/수 감각 학습 겸용) |
| 플레이 타임 | 1회차 약 20~30분 (5스테이지) |
| 기술 | TypeScript + Vite, 외부 에셋 0개(모든 그래픽/사운드 절차적 생성) |

## 2. 핵심 재미 (Core Loop)

```
 이동/점프 → 플러스 오브 수집 → 숫자가 커짐 → 몸의 모양·능력이 바뀜
      ↑                                              ↓
 체크포인트/코인  ←  새 스킬로 못 가던 길을 개척  ←  스테이지 공략
```

**한 줄 핵심**: *"내 숫자가 곧 내 몸이자, 내 스킬이다."*

숫자가 1 오를 때마다
1. **몸의 모양(히트박스)** 이 바뀌고 (1×1 → 2×2 → 3×3 …)
2. **이동 성능** 이 바뀌며 (작을수록 빠르고, 클수록 무겁고 점프가 높음)
3. **고유 액티브 스킬** 이 통째로 교체된다.

즉 "강해지기"가 아니라 "**달라지기**"다. 10이 항상 정답이 아니며, 좁은 틈은 1·2·3으로 줄여야 통과하고, 벽돌은 6의 구르기나 9의 슬램으로만 부순다. → **자발적으로 약해지는 선택**이 존재하는 것이 본작의 차별점.

## 3. 플레이어 규칙

### 3.1 숫자와 몸의 형태

블록 개수 = 숫자. 실제 블록 배열까지 재현한다.

| 숫자 | 배치(칸) | 히트박스 | 성격 |
|---|---|---|---|
| 1 | 1×1 | 1w×1h | 가장 빠르고 가장 약함. 좁은 틈 전용 |
| 2 | 1×2 | 1w×2h | 기본형 |
| 3 | 1×3 | 1w×3h | 길쭉함 |
| 4 | 2×2 | 2w×2h | 정사각형. 안정적 |
| 5 | 1×5 | 1w×5h | 매우 높고 얇음 |
| 6 | 2×3 | 2w×3h | 튼튼한 직사각형 |
| 7 | 2×4(1칸 빈칸) | 2w×4h | 비대칭 |
| 8 | 2×4 | 2w×4h | 큰 직사각형 |
| 9 | 3×3 | 3w×3h | 가장 넓음. 통과 제한 큼 |
| 10 | 2×5 | 2w×5h | 최대 크기. 무적 모드 보유 |

### 3.2 이동 파라미터 (숫자 n 기준)

- 최고 속도 `moveSpeed = BASE * (1.22 - 0.045n)` → 1일 때 가장 빠름
- 점프 초속 `jumpVel = BASE * (1 + 0.028n)` → 커도 제 키는 넘음
- 중력 `gravity = BASE * (1 + 0.035(n-1))` → 클수록 묵직함
- 코요테 타임 6프레임, 점프 버퍼 6프레임, 가변 점프 높이(버튼 떼면 감속)

### 3.3 숫자 증감

| 원인 | 변화 |
|---|---|
| 플러스 오브 `+` | +1 (최대 10) |
| `?` 블록 | 코인 또는 +1 오브 |
| 숫자 패드 `N` | 지정한 숫자로 즉시 변경(퍼즐용, 양방향) |
| 적/가시 피격 | −1 + 무적 1.2초 + 넉백 |
| 나눗셈 박쥐 | 숫자 절반(내림, 최소 1) |
| 제로 슬라임 | −2 |
| 1에서 피격 | 사망(라이프 −1) |

### 3.4 숫자별 액티브 스킬 (기본키 `X` / `K`)

| 숫자 | 스킬 | 효과 | 쿨다운 |
|---|---|---|---|
| 1 | **스피드 대시** | 수평 순간 가속 + 짧은 무적 | 0.7s |
| 2 | **더블 점프** | 공중에서 1회 추가 점프 | 착지 시 회복 |
| 3 | **트라이앵글 글라이드** | 유지 시 낙하 속도 1/4 | 없음(유지형) |
| 4 | **스퀘어 실드** | 2초간 피격 1회 무효 | 5s |
| 5 | **스타 핸드** | 별 발사체 발사(적 처치) | 0.45s |
| 6 | **롤링 어택** | 굴러서 돌진, 벽돌 파괴 + 접촉 공격 | 2.5s |
| 7 | **레인보우 브리지** | 앞쪽에 3칸 무지개 발판 6초 생성 | 3s |
| 8 | **옥토 그랩** | 대각선 갈고리 발사, 지형에 걸려 당겨짐 | 1.5s |
| 9 | **스퀘어 슬램** | 급강하 → 착지 충격파, 화면 내 적 기절 + 아래 벽돌 파괴 | 2.5s |
| 10 | **텐 파워** | 5초간 무적 + 자동 스타 연사 + 이동속도 1.6배 | 12s |

## 4. 레벨/오브젝트

타일맵은 문자열 배열이며 각 문자는 다음과 같다.

```
' ' 빈칸    '#' 흙/잔디 지형   'B' 벽돌(파괴 가능)  '?' 아이템 블록
'=' 한방향 발판              '^' 가시              'L' 용암
'o' 코인    '+' 플러스 오브    'H' 하트(라이프)     'C' 체크포인트
'P' 시작점  'F' 골 깃발        'N' 숫자 패드         'D' 이동 발판
'm' 마이너스벌레  'b' 나눗셈박쥐  'z' 제로슬라임  'Z' 보스
```

### 스테이지 구성

| 스테이지 | 테마 | 학습 포인트 | 신규 요소 |
|---|---|---|---|
| 1-1 카운트 초원 | 초록 들판 | 1→3, 기본 조작 | 플러스 오브, 마이너스벌레 |
| 1-2 벽돌 언덕 | 언덕/동굴 | 4·5·6 | 벽돌, 롤링, 나눗셈박쥐 |
| 1-3 무지개 협곡 | 협곡/하늘 | 7 다리 놓기 | 낭떠러지, 한방향 발판, 이동 발판 |
| 1-4 제로 동굴 | 어두운 동굴 | 8·9 | 용암, 갈고리, 슬램, 제로슬라임 |
| 1-5 제로의 탑 | 보스 아레나 | 10 | 보스전 3페이즈 |

## 5. 점수 / 리절트

- 코인 100점, 적 처치 200점(연속 밟기 콤보 ×2 누적), 플러스 오브 50점
- 클리어 시 남은 시간 ×10점, 노데스 보너스 1000점
- 하이스코어는 `localStorage`에 저장(스테이지별 최고 점수·최고 숫자)

## 6. 조작

| 동작 | 키보드 | 터치 |
|---|---|---|
| 이동 | ← → / A D | 좌/우 가상 패드 |
| 점프 | Space / ↑ / W / Z | ⬆ 버튼 |
| 스킬 | X / K / Shift | ★ 버튼 |
| 아래(하강/슬램) | ↓ / S | ⬇ 버튼 |

## 7. 접근성 / 난이도

- **어린이 모드**: 라이프 5, 피격 무적 2초, 낙하 즉사 대신 −1 (설정 화면에서 토글)
- 색맹 대비: 숫자 배지를 항상 블록에 표기(색만으로 구분하지 않음)
- 사운드 On/Off, 화면 흔들림 Off 옵션
- 60fps 고정 스텝 시뮬레이션(저사양에서도 물리 일관)

## 8. 비기능 요구사항

- 첫 로딩 < 1s, 외부 네트워크 요청 0회 (모든 에셋 절차적 생성)
- 단위 테스트: 충돌 해석 / 타일맵 파서 / 숫자·스킬 상태머신 / 점수 계산
